# Production rear Boost jet

Original Trackstorm geometry and materials, authored in Blender 5.2.2. `source/BoostJet.blend` is the editable master. It links `../source/TrackstormCar.blend` as the actual fit reference; the Car is not copied into the export or modified. `source/BuildBoostJet.py` reproducibly constructs the separate assembly, material batches, UVs, pivots, flame shell and preview deployment keys, then exports only the Boost collection to `BoostJet.glb`. Run it with Blender's background `--python` option from the repository. `sources.json` records tool version, source/export hashes and reference hash. The source directory is excluded from Godot import.

Blender uses metres, +Y forward and +Z up. glTF becomes Godot -Z forward/+Y up. Mount is fixed at Godot (0, .055, 2.36). The measured Car fascia ends at Z=2.205, bumper at approximately 2.345, lids/rack at approximately 2.09/1.97. Only the attachment brackets approach the fascia; the central assembly stays inside the rear lamp spacing. Outer collar radius is .412 m. Deployment translates straight rearward, with no sweep into the rack or trunk doors.

Keep `Mount/Sleeve`, `Mount/Nozzle`, `Mount/Ram_L`, `Mount/Ram_R`, `Nozzle/Outlet`, `Nozzle_Boost_Throat` and `Outlet/FlameSurface` names stable: runtime binds these authored nodes. Sleeve moves +.35 m Godot Z, nozzle +.72 m; rods scale Z from 1 to 1+.72/.26. The inner barrel overlaps the sleeve by .11 m at full travel. Outlet is (0,.055,2.875) stowed and (0,.055,3.595) deployed in vehicle coordinates. Preview keys are retained in Blender, but animations are not exported; runtime owns reversible state-driven motion.

Hardware has smart-projected UVs and original metallic/roughness materials. The 36-by-24 flame shell has explicit circumferential/longitudinal FlowUVs, a lobed profile and 3.4 m authored length. Godot's imported V runs from 1 at the outlet to 0 at the tip; the flame shader accounts for this. Runtime duplicates this shared mesh for the core and wisps and overrides the throat material. Smoke/sparks reuse the existing licensed Kenney textures; see the root third-party registry and [runtime contract](../../../docs/features/boost-exhaust.md).
