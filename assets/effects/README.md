# Proxy Mine explosion artwork

`ProxyMineFireball.png` and `ProxyMinePlume.png` were generated for Trackstorm with the built-in OpenAI image generator on 2026-09-30 after the user's approved direction for a realistic fireball flowing into a taller mushroom cloud. The prompts requested isolated, transparent-background photographic cutouts: a white-hot orange explosion with irregular flame edges, and a neutral volumetric smoke plume. They contain no external reference image, logo or third-party artwork. Runtime tint, billboarding and timed crossfade are authored in `ProxyMineExplosion.cs`. Existing spark and soft-smoke particles remain Kenney assets recorded in `assets/items/sources.json`.
