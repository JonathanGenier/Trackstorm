# Main Menu

The frontend presents Play, disabled Garage / Coming Soon, Settings and Quit. `DevelopmentSession` supplies the existing browser, Settings and cleanup-aware Quit actions to `HangingMainMenu`. Browser, lobby, Settings and gameplay presentation retain their existing owners. The separate Settings shortcut remains available on other frontend screens but is hidden on the Main Menu.

`HangingMainMenu.SetEntries` accepts independent IDs, labels, icon indices, availability, optional status and actions. Rebuilding changes plate count, vertical spacing, total height, viewport fit and connecting chain lengths. `HangingMenuPlate` uses a shared blank texture, independent icon atlas region, label and blank status backing. The selected shader changes color without changing the texture or alpha silhouette. [Artwork provenance](../../assets/frontend/main-menu/README.md) describes assets and typography fallback.

At the existing successful [startup](startup.md) reveal callback, the complete assembly begins above the viewport, accelerates down for 0.52 seconds, catches at its resting height, and settles with a single sub-seven-design-pixel lift over 0.6 seconds. Activation remains blocked until 1.12 seconds. No MenuShell media APIs participate in this animation. Hidden composition and every existing startup failure/retry gate remain in force. Returning from Settings or the browser retains the settled assembly.

Upper chains draw from fixed viewport-top points to the moving header; fixed-size link sections are revealed or clipped rather than stretched. Connecting chains move with the common artwork transform. Idle movement is a slow 2.4-design-pixel horizontal sway; flags add restrained cloth-only rippling below their fixed attachment regions. Artwork never moves the native hit targets.

The complete assembly and its stationary targets share a uniform scale of 75% of the viewport-fitting size. It hangs from the viewport top with a 4%-of-viewport-width left margin, leaving the right-hand background title unobstructed. Internal spacing and animation use the same design coordinates, so the smaller left-hand placement preserves chain connections and interaction alignment.

One selection follows enabled pointer movement or logical keyboard/controller focus. Directional navigation wraps through enabled entries, skips Garage, and repeats after 0.4 seconds at 0.12-second intervals. Logical input uses the existing remappable player binding owner. Native default navigation is consumed to avoid duplicate activation. Inputs held during entrance or a covering overlay are sampled without dispatch so they must be released before activation resumes. Settings/DevTools suspend the Main Menu's targets and navigation, with selection restored afterward.

`check-startup.ps1` exercises the production Loader reveal, phase-aware retries, blocked/held activation, mixed synthetic mouse/keyboard/gamepad input, disabled Garage, repeated navigation, Settings/browser return, stable hit rectangles and exact media-player continuity. `-Visual` captures entrance and selection states and checks 640×360, 1280×720 and 1600×900 viewport bounds. `check-menu.ps1 -Visual` covers existing Settings/gameplay/input/cleanup integration. Audible continuity and physical-controller ergonomics require direct listening and hardware testing beyond these assertions.
