## Implemented result

- Core computes a deterministic, pitch-only velocity correction from at most two bounded host terrain samples per active standard missile per 60 Hz step. Horizontal heading and speed are preserved; vehicles are never steering targets. The correction responds continuously to support proximity, with independent response, angular-envelope and pitch-rate bounds. There is no stored launch-angle classification or ground target.
- Client queries existing authored static drivable surfaces, excluding water and unauthored props. Core rejects unsuitable normals/slopes. Missing or infeasible support retains committed velocity exactly; downward discontinuities beyond sampled terrain tangents are treated as cliffs. Suitable nearby terrain can reengage correction repeatedly.
- Defaults: 1 m clearance, 30 m look-ahead, forward probe extent of ±10 m, 3 m current-support reacquisition height, ±35 degree requested pitch envelope, 45 degrees/s maximum pitch rate, response 8/s, 40 degree maximum surface inclination, 1 m discontinuity tolerance. These are tuning values, not guarantees of recovery at arbitrary speed or terrain geometry.
- Host authority, full-step collision sweeps, damage/impulse, event ownership and replicated membership remain on the existing paths. Curved projectile position/velocity uses existing motion publication; serializable velocity is sufficient to resume flight. Salvo arcs remain outside terrain guidance.
- Launch lifetime is the smaller of existing Ticks and the new seconds cap; defaults preserve 300 ticks / 5 seconds because the independent seconds cap defaults to 60. Lifetime changes apply to new launches. The 4096 m absolute world-coordinate bound retires out-of-bounds standard missiles without an impact; lifetime expiry likewise does not manufacture damage.
- Dedicated Missile DevTools group has 16 functional authoritative values: Speed, Ticks, Damage, blast radius/impulse, seconds cap, world bound, clearance, look-ahead, probe range, reacquisition height, pitch envelope, turn rate, response, slope limit and cliff tolerance. Existing stable keys retain their wire positions. All settings use existing validated Apply, synchronization, persistence and recovery; none are local decorative controls. Shared blast values retain their existing consumers.
- Internal configuration packet changed TC44 → TC45: 241 values / 1949 bytes. Old protocol packets are rejected. Game/build versions, export presets and documentation/verification indexes were not changed.
- Feature documentation and the fast-check routing table were updated. A durable native missile harness covers terrain, cleanup, multiplayer and production-map integration.

### Corrections and calibration

- Guidance samples current support plus quarter/half/full look-ahead distances (at most four native rays). Intermediate samples anticipate actual rising ground, including a bank that lies before the far endpoint.
- A lower future sample cannot command pitch beneath the current supporting tangent and clearance response. Descent follows actual local descent instead of pulling through a flat tabletop prematurely.
- Actual rising support can continue bounded upward correction when all forward rays are beyond the road edge. This uses measured support; missing current support still preserves committed velocity exactly.
- Final defaults are a 42-degree requested pitch envelope, 210 degrees/s maximum pitch rate (3.5 degrees per 60 Hz step), and response 24/s. Rate is configurable from 0–240 degrees/s; response from 0.1–24/s. Speed, clearance, sensing ranges, reacquisition height and 40-degree terrain slope limit retain their existing functional controls. The complete configuration layout remains TC45 / 241 values / 1949 bytes; no version was changed in this correction.
- Calibration was iterative: the 75/10 trial failed at ordinary speed; 150/16 with continued local support reached the top at 120 m/s but failed at 180 m/s; 180/24 reached the perimeter at 180 m/s with only 0.016 m minimum clearance. The 210/24 trial increased that high-speed minimum to 0.143 m. Actual moderate-ramp corrections stayed far below the cap, about 29.77 degrees/s. No instantaneous pitch replacement or yaw correction was introduced.
- Native query dictionaries are disposed after sampling. The production verification fixture drains freed viewport/native wrappers before shutdown; diagnostics are not suppressed.
- Added regressions for premature deck descent, a short bank before a missing far probe, and rising support with all forward probes absent. The existing bounded-query assertion now enforces the four-ray budget. Expanded tuning validation has explicit invalid-bound cases.
- The comprehensive gate exposed a stale braking test that selected `GameplayOptions.All.TakeLast(12)`, inadvertently checking Missile settings. It now selects its intended braking keys explicitly and verifies the complete key set. No braking behavior changed.
- Existing saved tuning overrides remain intact. To adopt these defaults in an existing session, use the Missile category's **Reset to Defaults**, which applies through the existing authoritative category-reset path. The harness uses isolated settings and did not overwrite the user's saved gameplay configuration.
