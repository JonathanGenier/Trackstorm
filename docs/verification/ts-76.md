## Iteration evidence

Blender 5.2.2 LTS authored/exported the set. Godot 4.7.2 .NET imported it.
Windows visual checks used the GTX 1070 Compatibility renderer.
The first Structure run passed 2,598 support probes, 102 clearance rays,
twelve crossings on both axes (three passes in each direction), and four native
15 m/s pier impacts. Traversals retained 1000/1000 HP and zero unsupported frames;
impacts stopped at vehicle-origin Z approximately -13.47 m and registered damage.

Runtime inspection led to neutral shading correction (initial export appeared
overbright). An isolated impact run exposed a fixture issue: the first sample
observed the old pose before Core's queued reset applied. The fixture now waits
three native frames and asserts the setup pose before recording the impact.
The corrected isolated visual impact run passed. No vehicle behavior was changed.
A subsequent targeted check also passed retaining-wing, drain-invert and deck
barrier collision probes with all common geometry checks and native impacts.

Independent engineering review caught an export-fidelity defect: Blender's
default GLB export omitted the retained bevel modifiers. `export_apply=True`
corrected it; the regenerated GLB is 380,256 bytes. Independent reinspection
verified chamfered geometry in all 62 meshes, identity transforms and matching
manifest hashes. The [engineering verdict](ts-76/engineering-review.md) is PASS
after correction. Asset-dependent runtime checks are repeated on that export.

Initial sandbox import/log access errors and a cached NuGet vulnerability-feed
error were resolved using authorized normal-access import and a forced NuGet
restore; subsequent Debug build passed with zero warnings/errors.

## Scope interpretation and limitations

The approved terrain has no reachable elevated crossing and preserves both
ground-level axes. Adding deck approaches would change that topology and jump
recovery space, so the structural deck is not claimed as an elevated route.
Existing jumps remain terrain; there are no replacement manufactured ramps.
The obstacle reservations are unchanged. Material identity, water gameplay and
environment dressing remain outside TS-76.

The existing uphill-start limitation is deferred outside terrain/structure scope.
It must be reported if encountered by the comprehensive infield suite.
Automated native driving establishes physical traversal, not human control feel.
Human keyboard/controller playtesting, dense combat, exported builds, remote
devices, authenticated EOS, audio listening, all off-route impacts and ordinary
chase-camera occlusion throughout the tunnel have not been verified here.
