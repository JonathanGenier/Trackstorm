## Assumptions, limitations and unverified areas

- The 32-vehicle fixture uses scripted poses and accepted snapshots; it is not a 32-peer networking benchmark. Its 16.71 ms p95 includes the 60 FPS cap and is not an uncapped GPU budget or low-end hardware guarantee.
- Two-peer native transport was exercised locally, including impairment. Distinct-device EOS, WAN, exported builds and high-player-count network sessions were not exercised for this Story.
- The scripted moving inspection uses 6 m/s to keep geometry visible. Native Nitro checks provide real high-speed driving separately. Automated input sequences and direct runtime observation do not establish human controller ergonomics.
- Direct jet/rack coexistence is a deliberate visual fixture condition; normal selected Nitro keeps the rack clear. No new collision hull is added for cosmetic rear hardware, and particles do not collide with scenery.
- Practice has the same component but no item authority/grant path for ordinary Boost activation; live Boost verification uses network arenas.
- Presentation phase is reconstructable and not replicated. Fresh active state deploys locally; authoritative physics begins immediately and is not delayed by the .24 s visual deployment.
- Rendering was assessed on the Compatibility renderer/GPU above, in the clear-day environment. Other graphics hardware, all weather/lighting presets and extreme camera poses remain unverified.
- The initial nonreproduced articulation teardown diagnostic remains a recorded runtime uncertainty.
- Pre-existing `assets/maps/oval/grass_variation.png.import` user change is preserved and excluded from this Story's commit. The postponed-work backup stash is preserved.
