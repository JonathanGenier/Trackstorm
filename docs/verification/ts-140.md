## Limits

- **VERIFIED:** Fresh Core match construction selected more than one seed across eight matches; the effective configuration and lobby revisions advanced. Checkpoint restoration matched the saved selector state and the next authoritative pickup draw. Native harnesses exercised pickup ownership, reconnect and migration state paths.
- **INFERRED:** Application rematches use the same fresh host construction path. The item-spawn native fixture deliberately supplies a fixed seed, so native runs did not directly compare random first-draw sequences across live rematches.
- **UNVERIFIED:** Authenticated multi-PC EOS/Internet recovery, exported build behavior and long network soak. Local UDP and trusted-identity harnesses do not establish those outcomes.
- No new assets or dependencies. Core remains engine-independent and the production gameplay dependency remains Client to Core.
