### Implemented

Nitro now adds a central **18,000 N chassis-forward force**, independently of engine demand, throttle, wheel traction and supporting material. Acceleration from that force is thrust/mass. Normal drive combines with it; reverse/braking opposes it without reversing the rocket. Airborne force uses a runtime fraction (default 1, zero disables it). Only added forward velocity is bounded by the boosted speed limit; existing momentum is not snapped to that limit. Release removes thrust immediately; the existing bounded overspeed recovery continues.

All required tunables use the existing Configs authority, UI, persistence and complete replication/checkpoint paths: consumption, forward thrust, speed multiplier, airborne fraction, overspeed recovery and Circus overspeed rate. The old acceleration-multiplier key no longer changes behavior; existing persistence retains unknown keys and defaults new keys without guessing a physical conversion. Movement is version 7 / 127 bytes, and configuration is version 14 / 110 keys. Prediction and restoration carry force, speed multiplier, airborne fraction and the existing charge-derived prediction budget. No second resource or physics owner was introduced.

The percentage resource, disposal, two-slot selection, HUD charge, actual authoritative horizontal-overspeed scoring, current K/D multiplier and notification deduplication remain in their existing owners. TS-161 collision code was **not added to this Story**. Compatibility was executed in an isolated checkout described below; Nitro introduces no wall assist or special collision mode.
