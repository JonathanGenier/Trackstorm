## PR #75 headless startup-verification correction — 2026-09-22

Jira TS-122, its approved changes and [CI run 35681182824 / job 106599360583](https://github.com/JonathanGenier/Trackstorm/actions/runs/35681182824/job/106599360583) were inspected. That Windows job checked `ecfaa13` with pinned Godot 4.7.2 and failed the real-click Direct-IP Back assertion at `StartupIntegrationChecks.cs:184`. Jira records this bounded correction and explicitly does not authorize another formal critique, unrelated practice work or visual polish. Current main remains `a6f1f8f`; synchronization/version checks retain `0.1.25` / `0.1.25.0`.

### Reproduction and cause

The unmodified local headless harness reproduced the exact failure (`.godot/ts-122-ci-reproduce.log`). Temporary diagnostics established that **all three predicates failed**: stage remained `LobbyBrowser`, `menu.Visible` was false, and Direct-IP remained selected. The Back control received mouse-button input events but emitted **zero** `Pressed` signals. Its rectangle was `(-244, -249), (552, 31)`, with click center `(32, -233.5)`, outside the viewport (`.godot/ts-122-ci-diagnostic.log`).

The headless Window defaulted to **64×64**, so the fixed-size centered browser was clipped and its Back button could not participate in valid pointer activation. This was fixture viewport setup, not a production Back/reset/navigation defect. Supplying `--resolution 1280x720` alone did not change those bounds or fix the failure (`.godot/ts-122-ci-resolution.log`). Setting the actual Window size before composition moved Back to `(364, 79), (552, 31)` and real clicks immediately restored all three predicates. The controlled diagnostic run reached every navigation assertion, but temporary duplicate diagnostic subscriptions produced errors; those temporary subscriptions were removed before final verification, not accepted as a passing run.

### Correction

Only the startup verification fixture and documentation change. The fixture sizes its actual Window to 1280×720 before composition and reports the initial/effective dimensions. Its click helper rejects invisible, empty or off-viewport targets. The repeated path retains genuine Godot mouse motion/down/up delivery; Direct-IP selection and the earlier browser Back now also use real clicks instead of programmatic state/signal shortcuts. Newly shown browser content receives two layout frames before clicking Direct-IP. Each repeated Back click must emit exactly one `Pressed`, immediately restore Main Menu stage/visibility and clear Direct-IP. Original composition, input, animation and media assertions remain. The temporary observer is disconnected in `finally` on every cycle.

No production navigation, window defaults, cleanup, layout, scale, flutter, media owner or practice code changed. No assertion was skipped or weakened, and no failing click was replaced with signal emission.
