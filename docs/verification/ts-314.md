### Failures investigated and fixture corrections

The first restricted runtime run reported sandbox access errors for user logs/certificates; subsequent native runs used normal filesystem access and exited cleanly.

The old uphill fixture applied a horizontal impulse into a bank. With angled panels it climbed 0.31 m rather than the required 1 m; unchanged main was built and exercised as a control and passed its full harness (1.09 m climb). Tracing showed most speed loss in the first native step. Margin, sleep and mass-frame experiments did not resolve it and were removed. The support-following fixture now applies a tangent impulse along the bank, preserving the same horizontal component, alignment tolerance and minimum climb assertion. It climbs 1.09 m and passes the full harness. This isolates support following from shape-dependent into-ground contact response; it does not claim identical response to the original horizontal impulse. Production friction, damping, mass, inertia behavior and stabilization code were not changed.

The first comprehensive run had 1,484 passing Core tests and one Salvo fixture failure: its former straight-wall edge impact now lies outside the armor and correctly receives blast falloff (972.71 remaining HP rather than 750). The fixture now strikes the actual angled wing tip and still asserts exactly one full-damage hit. Focused tests and the complete gate were rerun successfully.
