## Implemented behavior

- Added reusable, validated per-surface braking responses for Asphalt, Dirt and Grass, independent of their ordinary driving grip. Per-wheel service/handbrake demand, longitudinal capacity and lateral release now distinguish deliberate slides without reducing normal propulsion or altering TS-268 steering interpretation.
- Defaults retain ordinary grip 3 / 2 / 1.9. Braking effectiveness is 1 / 0.8 / 0.6, rear service-brake lateral purchase 0.9 / 0.55 / 0.2, and moving handbrake grip scale 1 / 0.45 / 0.16. These multiply existing global handbrake purchase and use its progressive application/release.
- Grass uses bounded steering allocation and yaw recovery, preserving countersteer opportunities. Its front reserve fades as the wheel centers, restoring passive lateral correction. Dirt extra corner capacity is reduced from 120% to 20% and resolved per supported Dirt wheel instead of applying a center-selected boost to every wheel. Ordinary powered input never rebuilds automatic PowerSlip.
- Below 0.5 m/s contact-plane speed, held handbrake applies traction-limited static friction after gravity, interrupts drive immediately, and suppresses yaw within the available tire/brake budget. It does not anchor a pose or introduce hidden continuation state. Missing support/drive permission, water immersion and insufficient traction do not produce an artificial hold.
- Twelve Developer Options use existing validation, Apply/Cancel/Reset, persistence and host configuration delivery. TC37 contains 213 keys / 1725 bytes; old TC36 wire payloads reject. Missing saved keys inherit defaults. Movement snapshot layout remains unchanged.
- Existing imported geometry, material field, collision and per-wheel identity remain the reusable owners. No map-specific handling exceptions or new mud/water tuning or authoring were added. Updated feature documentation and native/deterministic verification.
