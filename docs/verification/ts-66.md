- `GameVersionTests`, `OnlineLobbyTests`, `OnlineLobbyUiChecks`: new parsing/source-metadata, compatibility, wire, allocation, reconnect, metadata/browser and rendered-control coverage. Existing lobby/reconnect/event/activity/vehicle tests now explicitly supply the canonical version to the authority APIs.
- Feature index, game-versioning, sessions, reconnection, EOS lobbies, Developer Options, EOS setup and workflow documentation describe the resulting contracts and verification procedure.
