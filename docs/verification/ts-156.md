## Assumptions, limitations and risks

- Uses the existing post-combat current K/D multiplier. Different patches remain independently eligible on simultaneous entry, while physical spin remains bounded per vehicle per step.
- Native recovery fixtures seed Oil to isolate restoration; they do not themselves drive a new scored rival crossing immediately after every reconnect/migration. Deterministic tests cover that scoring continuation and latch preservation.
- Local UDP/native worlds share one PC. EOS authentication uses no real remote identities in these harnesses. Existing migration rollback replaces totals with its chosen checkpoint; later discarded outcomes are not guaranteed durable.
- Expanded match packets remain below 18 KiB. Worst-case packet shape is deterministic test evidence, not a full-roster native load/soak benchmark.
- No unresolved in-scope production defect was identified. Matching game builds are required because the match codec changed.
