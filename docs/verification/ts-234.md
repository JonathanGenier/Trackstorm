## Assumptions and limitations

- The approved image is an art direction reference, not an engineering model. The fixed production rack has crossmembers absent from the sketch. Feeds pass through a concealed central bearing throat and drums occupy a smaller central envelope to clear the actual structure. This is a production-fit adaptation, not a literal 100% reproduction of every drawn proportion.
- Both barrels bracket one authoritative firing axis. The shared muzzle plane matches barrel length; alternating ±0.145 m barrel flashes are cosmetic. No independent dual-ray firing or replicated per-barrel state was introduced.
- Dedicated eight-weapon presentation uses scripted confirmed events. Actual network evidence uses two shooters/three peers and separate impaired native Machine Gun checks. These are distinct tests.
- Belts are game animation geometry, not a physically simulated feed mechanism. The bounded confirmation buffer avoids replaying a delayed backlog after release. Runtime observations cover sampled articulations, not exhaustive mesh-intersection certification.

## Unresolved risks
