## Failures exposed and corrected before critique

- Initial low-boulder collisions produced roughly 16 m/s upward speed because bevels were classified as support. Corrected classification and wheel observation; final rock tests stop without that launch.
- Overlapping module caps caused false head-on damage/stopping at seams. Exposed-surface contact queries corrected box seams; replacing oval overlap prisms with a continuous perimeter corrected the production geometry failure.
- A centered network pier initially converted contact into roughly 11.7 m/s sideways motion. Progressive direct-manifold dissipation corrected this; final centered pier lateral displacement is about 0.14 m.
- The first eight-peer impaired run failed with `Host acknowledgements stalled; reconnect to resynchronize`, frame stalls and failed-run cleanup warnings. Removed the unconditional extra wheel queries from obstacle-free network steps. This failure is retained in [initial impaired log](ts-161/network-impaired.log).
- The newly added UDP harness initially used the wrong replicated-state accessor, causing the first GdUnit build attempt to fail. Corrected to `ReplicatedVehicle.State`. Its first successful behavioral run exited before queued arena cleanup and reported leaked resources; allowing normal deferred cleanup produced a clean passing rerun. These were verification-harness defects, not hidden successes.
