Implemented on the existing `ts-28-pg` Story branch. TS-28 and TS-29 descriptions, comments, attachments and remote links were inspected and reread before delivery. Both board and HUD consume the same Core rank projection. Finished forces the same board visible. Results expose the existing Return/Leave actions. Monotonic expiry, exact roster/session/generation matching and immediate interruption clearing prevent stale diagnostics being reused across reconnect. Disconnected reserved players remain represented, with unavailable ping. Ping has no gameplay or ranking input.

## Limits and acceptance coverage

VERIFIED: deterministic ranking, eight-player roster projection, authoritative replicated kills/deaths, matching native HUD rank, synthetic keyboard/controller behavior, persistent Finished results, correct winner identity, transport-neutral diagnostics, safe missing/stale values, rebind identity protection, and rendered responsive layout. The standings fixture installs authoritative match boundaries to isolate replication/presentation; real lethal scoring was checked separately by the match harness.

INFERRED from code plus provider-independent tests: the same UI/presentation path operates over real authenticated EOS. EOS has no available native RTT metric in the current adapter, so numeric EOS ping is not claimed or fabricated.

UNVERIFIED: separate-PC authenticated EOS standings during Internet interruption/reconnect, physical-controller ergonomics, and human art-direction acceptance. TS-29's live EOS integration criterion remains unverified in that environment. No known functional acceptance criterion is intentionally omitted. Receipt-based TTL cannot measure time spent queued before arrival without synchronized clocks; this limitation is documented in the feature guide.

The pre-existing whitespace-only `InputButtons.cs` edit initially failed warnings-as-errors. Its original bytes were preserved in `.godot/ts28-original-InputButtons.cs.txt` before normalization. The file now matches `main` and is absent from the Story diff.
