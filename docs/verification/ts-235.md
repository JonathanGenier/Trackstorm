### What changed

- Reproduced the reported frame-order defect before the fix: a new moving/rapid-aim
  regression measured **0.445328 m** between the first streak origin and its
  rendered barrel. Network receipt sampled the old pose before vehicle presentation,
  weapon yaw/pitch and recoil updated. Earlier still-pose checks missed this ordering.
- Network receipt now reserves within the same fixed pool. Render priority 100
  captures each muzzle after those presentation updates, once on the first displayed
  frame. The pool is explicitly world-space with engine interpolation disabled,
  matching the arena's existing manual interpolation. Already-launched rounds keep
  their world-space path toward the unchanged authoritative endpoint. Matching visible
  payloads can supply the terminal shot's muzzle as retraction begins.
- Both real guns retain their alternating actual-round identities. Per-gun sequence
  is **gold, gold, red** on the left and **gold, gold, green** on the right. The
  default shared interval is three, still tunable through the existing host catalog.
  It uses actual shot ordinals, independently of configured ammo cost, release,
  publication batching and restored magazine state.
- Increased gold opacity/intensity and colored intensity without widening or
  lengthening default geometry. Alpha blending keeps hue against bright backgrounds;
  there are no new lights or bloom effects. Eight local VFX controls replace the old
  nine: separate gold/tracer intensity controls replace brightness/random color shares.
  Defaults are 1.35 gold and 2.5 colored intensity, with bounded ranges. Existing
  speed/length/width, flash and smoke controls retain their owners and reset behavior.
- Preserved 512 total / 64-per-shooter slots (including pending emissions), 550 ms
  lifetime, endpoint clipping, duplicate/recovery guards and no per-round scene nodes.
  This round adds no wire fields: TI33, TC56 and compatibility bucket 25 remain.
