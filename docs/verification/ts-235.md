## Implemented

- Replaced full-ray cylinders and oversized tracer spheres with travelling,
  tapered streaks: dim 1.1 m ordinary bullets and stronger 4.2 m authority-selected
  tracers. No extra random spread or independent projectile simulation was added.
- Each streak starts at the appropriate production barrel tip with current yaw,
  pitch, recoil and vehicle transform, then converges to the unchanged confirmed
  endpoint. Confirmed magazine consumption supplies the same left/right sequence
  to the rig and outgoing VFX, including either slot, batching and partial-magazine
  reconstruction. The original alternating firing order and tracer flags remain.
- One arena-owned MultiMesh preallocates 512 instances, capped at 64 per shooter.
  Outgoing flights create no per-round nodes, meshes or materials. Cosmetic speed
  is 600 m/s; flights clip to accepted endpoints and expire within 550 ms.
  Catch-up drops excess presentation instead of queueing a delayed burst.
  Zero-length/behind-origin segments are suppressed, duplicate publications do
  not replay, and resynchronization clears existing flights.
- Core gameplay, hit queries, ammo/cadence, damage/falloff, spread, protocol and
  existing impact sparks are unchanged. Added a procedural original-project shader,
  focused checks, preload/routing and affected feature/asset documentation.

## Assumptions and limitations

- Visual flight is cosmetic; native damage and existing impact feedback remain
  immediate. Barrel-to-endpoint parallax is intentional and does not change hit
  geometry. The authority still selects every second round as a tracer by default,
  so the brighter shots follow that selection rather than an invented per-barrel rule.
- Eight-shooter stress and 30/60 FPS comparison use scripted accepted publications
  and production rigs. Actual network evidence uses two shooters/three peers on
  one machine. These are different kinds of evidence.
- Jira supplies no model recommendation. Implementation and the runtime critique
  below used the current GPT-6 Astra session; no independent engineering PR review
  or human acceptance is claimed.
