## Implemented behavior

- Held remappable Shift/LB explicitly enables air control only while unsupported and outside crash recovery. Time airborne and normal throttle/steering never create aerial intent. TS-268 ground steering and TS-266 surface/handbrake physics retain their owners.
- Separate pitch/yaw/roll axes: Shift+W/S pitch, A/D roll, Q/E yaw. LB+left stick pitch/yaw; LB+A redirects horizontal stick to roll. A release restores yaw; Shift/LB release clears air torque/stabilization while preserving momentum. Neutral axes with modifier held retain existing angular damping.
- RT throttle, LT brake/reverse, B handbrake, Y use, X switch. Contextual E yaw cannot leak weapon switching, including press/release sequences within one capture interval. X remains usable with LB.
- Controls exposes Controller Deadzone (0-0.95; default .15), Steering Sensitivity and Aerial Sensitivity (.1-3; default 1). Ground sensitivity consumes TS-268 shaping; aerial gain is independent and linear. Keyboard input remains full strength. Existing deadzone owner and trigger behavior retained; valid saved values below 1 still load.
- Existing settings persistence, retry/debounce and remapping architecture retained. Binding revision 2 migrates exact old defaults only, preserving custom/unbound mappings. No camera settings added.
- Input frame v2 is 27 bytes; vehicle protocol v15. Host gap bridging, tick rebasing and prediction preserve aerial axes. Removed obsolete air activation delay and duplicate deadzone configuration; TC38 has 211 controls/1709 bytes. Old retired saved keys ignored; vehicle continuation layout unchanged.
