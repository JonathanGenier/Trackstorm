## Implemented behavior

- Hosted authoritative Missile blast radius now defaults to `VehicleDimensions.Length`, **5.06 m radially**, using the production Car's documented collision hull. Cosmetic bumper rails extend beyond that hull; this is an approximate Car-length calibration, not an inferred visual mesh bounding box. Peak hosted damage remains 300 HP and impulse 15,000 N·s, with existing linear falloff, zero edge, owner inclusion, shield handling and other damage rules. Salvo retains its own radius/rules. The engine-independent item default damage remains its previous 55 HP; hosted configuration retains its previous override.
- The existing authoritative `items.explosion_radius` control remains in Missile Configs, with normal host validation, replication, reset, export and recovery. No new gameplay codec or radius authority was introduced.
- Reliable confirmed Missile collision events create a short lobed orange/red/gold fire bloom, faint short smoke, and red/gold/ivory-white cosmetic fragments. The default outer artistic radius is **2.25 Car hull lengths / 11.385 m**, independently adjustable; 2.5 lengths is 12.65 m. Fragment paths have no collision, damage, knockback, secondary hits or terrain queries. The central fire remains inside the shared blast envelope. Miss expiry and silent removal never create an explosion.
- Device-local explosion intensity, central fire scale, cosmetic reach, density and duration have operative native controls and independent category reset. Each impact captures these session-only settings; existing effects finish with captured values. They never enter gameplay Apply/Cancel, persistence or the wire state. Existing host-saved gameplay radius overrides remain valid; reset/edit the authoritative radius to select the new default.
- Each default effect owns seven shared-mesh fire lobes, one 160-instance fragment batch and 18 smoke particles. Density caps fragments at 320. At most 32 live effect owners coexist; further impacts replace the oldest cosmetic owner. Captured-duration expiry and arena teardown free effects. Existing CC0 Kenney smoke and an original procedural shader/native meshes use the existing loader; no new external asset, Blender export or audio was added.
- Added the focused native explosion harness and boundary/tuning Core tests. Updated existing assertions affected by the smaller radius and synchronized affected feature/asset notes.
