## Limitations and outside-scope findings

- **VERIFIED:** Supplemental migration and reconnect runs report success for behavioral assertions, then fail their strict warning/error checks at process shutdown. Migration verbose output identifies retained WAV/MP3 playback resources; a repeat normal run still warns. These fixtures do not instantiate DevTools. **INFERRED:** this is existing audio teardown behavior rather than TS-97 UI logic; no baseline binary comparison was performed. Audio teardown fixes are outside TS-97 and were not made.
- **VERIFIED:** The existing GdUnit bootstrap test fails at line 24 because it expects `DevelopmentSession` immediately after adding the main scene. Current main has `StartupEnabled = true` and creates that session through staged startup. The unchanged test and bootstrap source demonstrate the mismatch. The current startup harness passes. Updating this older test is outside TS-97 and was not done.
- Native networking evidence is same-machine UDP with trusted identity seams, not authenticated multi-PC EOS. Physical gamepad ergonomics, OS focus/capture behavior and a new exported Release executable remain manual validation items. Rendered Godot UI and synthetic keyboard/controller/axis input were exercised; Release compilation/tests passed.
- At 640x360, the deliberately persistent header, Force Start, search and footer leave a small scrolling settings area. Native focus-follow and all action bounds passed; developers should assess this tradeoff on their target display.
- Host-only mutation controls remain hidden for clients. The existing session/epoch draft-reset policy is preserved. Force Start and practice actions remain immediate actions, not staged settings.
