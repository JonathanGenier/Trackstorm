## Implemented

- Existing `ItemHudSlotView` reads each physical magazine's exact remaining count and captured capacity; no client ammunition store or predicted consumption.
- Existing `ItemHudSlot` draws eight linked pointed brass cartridges, an integer readout and ROUNDS legend. At <=20% acquired capacity, count/icon become orange and the legend says LOW AMMO. A zero-resource projection shows EMPTY; authoritative depletion removes the item and clears the shared slot normally.
- Capacity default is 500 per item, 1,000 across two fresh items. Existing DevTools configuration still governs new acquisitions; live magazines retain captured capacities. Five-digit values use a smaller count font.
- Firing cadence, alternating barrels, hit/damage rules, ammo-per-round cost, pickups, selection, discard and lifecycle ownership remain in existing Core systems. Only the approved capacity default changes gameplay configuration.
- Updated deterministic/native expectations and feature documentation. Story version synchronized to 0.2.63 (export 0.2.63.0).
- Native Machine Gun fixture derives expected remaining ammo from captured capacity; its far-range sample is four seconds instead of six so release/reuse is exercised before the smaller magazine exhausts.
