## Limitations and unresolved risks

- Normal two-slot rules remain authoritative. When the parked inventory is full, the
  respawned crate stays available until a slot is freed. Its visible crate and ITEM label
  overlap the car; this presentation limitation remains.
- Existing route following has no dynamic obstacle avoidance. The 100 m gap is approximate
  during normal laps, not guaranteed immediately after collisions, death/respawn, tuning
  changes or forced moving-car displacement.
- **UNVERIFIED:** authenticated EOS, independent machines/remote networks, exported
  builds, physical-controller feel, human 360-degree camera playtesting, audio quality
  and long-duration performance. UDP peers used isolated worlds in one process with
  trusted test identities; these were not EOS sessions.
- Camera evidence uses synthetic input and rendered captures. It supports later TS-302
  experimentation, but does not implement or certify future camera/crosshair/aim refinements.
- User assigned main/version synchronization, static review, PR creation and CI readiness
  to the independent delivery reviewer. Versions/main were not updated here. The commit
