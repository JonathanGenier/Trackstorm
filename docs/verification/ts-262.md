- Existing mechanical/weapon fixtures now provide fresh aim and wait for deployment instead of assuming immediate chassis-forward firing. The shared native aiming fixture now validates actual camera-directed bursts, multiple sustained shooters, remote outcomes and presentation, expiry, suppression and switching before its existing camera/lifecycle matrix.

### Implemented behavior

- The existing shared aiming owner acquires only a cursor-intersected living rival car with visible body centre. It retains that identity through bounded small misses/movement, rejects intervening cars/cover, and clears on eligibility, capability/life, suppression, accepted-aim expiry and reconstruction boundaries. No new target authority or networked lock exists.
- Actual camera attraction converges at 8/s, capped at default 18 degrees/s mouse and 24 degrees/s controller through shared host tuning. Active engagement holds recentering; deliberate aim-away or a sweep past centre releases with a short reacquisition delay. Ordinary chase return remains outside engagement.
- The same framed car's displayed world-space body centre supplies pivot-relative desired aim through ordinary authority acceptance. Without it, free fire uses the centered camera ray and configured spread. Readiness, articulation, self-clearance, closest collision and current accepted aim still control every shot.
- Authoritative spread is a fixed **0.42-degree half-angle** using the unchanged deterministic random samples/distribution. It is independent of target identity, geometry, range and hit counts. Damage/falloff, 225 m maximum range, cadence, ammo and sustained-use behavior are unchanged. No hit quota, reroll, homing or cosmetic shot correction exists.
- Existing body-envelope brackets retain their disconnected corners; the previous seven-pixel padding was removed rather than enlarged to satisfy the benchmark. Host configuration version 44 carries two additional attraction controls (228 values / 1845 bytes). Host seed schema 3 migrates only the previous persisted six-degree default once, preserving other custom tuning and explicit new-schema overrides.
