## Evidence limitations

Fixed-FPS harness runs advance 60 Hz simulation faster than wall time when possible;
reported simulated durations are not claimed to be equal wall-clock durations.
Frame intervals include renderer/scheduler/vsync effects and are not isolated GPU
profiling. Managed retained-memory samples are not a zero-allocation claim for the
entire vehicle simulation. Native ray query wrappers and pre-existing simulation
work still allocate; persistent mark storage, nodes and geometry remain bounded.

The stress fixture uses eight real native vehicles repeatedly reset onto surface
lanes. It isolates continuous emission, recycling and retirement. Production-map
and multi-process network checks are separate evidence, not eight human-operated
remote machines. Water screenshots can contain old dry-surface tracks elsewhere
because the fixture changes one pad's identity between scenarios; the Water scenario
explicitly verifies zero new persistent marks.

Budget edits deliberately clear marks, and appearance/lifetime edits apply to new
emissions. Distance applies immediately; disabling density allows existing marks
to finish fading. The fixed maximum allocation remains reserved at low budgets.

Real multi-device/EOS play, remote WAN latency, lower-end GPUs, multi-hour wall-clock
soaks and hourly clock rebasing are not established by these checks. No claim of
physical-controller ergonomics or subjective human playtesting is made.
